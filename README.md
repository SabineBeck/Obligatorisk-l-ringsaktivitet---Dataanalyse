Data Science Projekter – Semesterarbejde og Specialisering

Dette repository fungerer som en samlet portefølje over mine projekter og opgaver gennem studiet, med særligt fokus på dataanalyse, machine learning, visualisering og applikationsudvikling📊 Projekterne spænder bredt – fra sportsanalyse og forudsigelsesmodeller til datavisualisering og clustering – og er udviklet med teknologier som R, Shiny, SQL og Python.

Formålet er ikke kun at løse konkrete faglige opgaver, men at opbygge skalerbare, praktisk anvendelige modeller og dashboards med fokus på transparens, performance og formidling🔍 Der lægges vægt på både statistisk forståelse og teknisk implementering.
